# PLAYTAPE — one-page cheat sheet

*Print this, or keep it next to the computer for a first session.*

## Making a song

1. Click a **blank cassette** on the shelf (or **Start a new song**).
2. Press the big red **●**. It arms itself — nothing else to set up.
3. Sing, clap, talk, or play — then press **●** again to stop.
4. Press **▶** to hear it back.
5. Press **+ Track** for another layer. Repeat!

## The buttons on the shelf

| Button | Does |
|---|---|
| Blank cassette | Start a brand-new song |
| Any other cassette | Open that song |
| Gold sticker on a cassette | This song has a finished mixdown |
| ✕ (on hover) | Remove a song from the shelf (doesn't delete the files) |

## The gear icon (Workshop)

- **PLAY / ARRANGE / STUDIO** — pick how much of the machine you see.
  Nothing is ever locked; switch any time.
- **Calm mode** — turns off all blinking and animation.
- **Loudness limit** — nothing can ever get too loud.

## Playing instruments

| Icon | Instrument | How to play it |
|---|---|---|
| 🎹 (blue) | Keys | Mouse, computer keys, or a MIDI keyboard |
| 🥁 (orange) | Drums | Click the grid, or the five pads above it |
| 🎸 (purple) | Pocket Synth | Slide your finger/mouse across the pads |
| 🎵 (blue circle) | Tuner | Shows the note you're playing |

## Computer-keyboard piano (when Keys is open)

```
 S D   G H J     <- black keys
Z X C V B N M   <- white keys, one octave

↑ / ↓  = move up or down an octave
```

## Finishing a song

- **Bounce** → makes one finished audio file of everything together.
- **Export stems** → makes a separate file for each track.
- Pick **WAV** (bigger, perfect quality) or **MP3** (small, easy to share)
  next to the Bounce button.

## Saving

- **Ctrl+S**, or the **Save** button, saves your song as a folder you can
  find again from **Recent**.
- PLAYTAPE also quietly backs up your work every 45 seconds by itself.

## If something looks stuck or broken

Just reload the page (or reopen the app). Nothing is ever lost except the
last few seconds of a take in progress.
