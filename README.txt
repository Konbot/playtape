TAPE + PLAYTAPE
================

Two tape machines, one install:
  TAPE      — the full portastudio.
  PLAYTAPE  — the same engine for young musicians (5-15) and anyone
              who wants a simpler way in. Songs made in PLAYTAPE open
              in TAPE unchanged — it is the on-ramp, not a toy.

INSTALL / UPDATE (same thing):
  1. Make sure Python is installed (python.org).
  2. Double-click INSTALL.bat.
  3. Two icons appear: TAPE and PLAYTAPE (Desktop + Start Menu).
  Projects are never stored in the install folder; updating never
  touches your music.

PLAYTAPE IN 60 SECONDS:
  - It opens on the SHELF: your songs as cassettes. Songs with a gold
    sticker have a finished mixdown.
  - The WORKSHOP (gear button) has three stages — pick what fits:
      PLAY     record & listen, big buttons, one knob per stripe
      ARRANGE  cut clips, loop & punch-in, drums grid, macro knobs
      STUDIO   full mixer, pedal effects, stems, MP3, MIDI learn
    Nothing is locked. Kids choose their own stage (Montessori-style).
  - Instruments: your voice/mic, Drums, Keys (4 sounds), Pocket Synth.
    KEYS plays from the mouse, the computer keyboard (Z-row + Q-row,
    arrows = octave) or a plugged-in MIDI keyboard, with velocity.
  - CALM MODE (workshop) stops all blinking and animation, and the
    loudness limit means nothing can ever get painfully loud. The
    limiter is always on.
  - Every knob is a real machine knob: it clicks in little steps,
    snaps to its home position, and double-click resets it.

GRADUATING TO TAPE:
  Open any PLAYTAPE project folder from TAPE (Open button). Everything
  transfers: tracks, clips, knob settings, loop region, even the drum
  pattern. TAPE simply shows more of the same machine.

WHERE FILES GO:
  Save (Ctrl+S) writes a project folder wherever you choose. Bounce /
  stems land inside a saved project's folder, otherwise in Downloads —
  the status bar always says which.

IF SOMETHING BREAKS:
  Re-run INSTALL.bat (it repairs). The launcher checks itself and will
  tell you plainly if something is missing.
